# Monatsausblick: additional 1961–1990 climate reference

Goal: keep 1991–2020 as the default; allow 1961–1990 for temperature, rain
and sunshine. Absolute observations and forecasts must not change.

1. Extend DWD monthly and HYRAS daily precipitation builders to select the
   30-year reference. Compare actual calendar-day sums with official monthly
   normals, including the correct leap-year fraction. Build a dedicated
   verified daily cache from all 30 official annual files, checking actual
   calendar and sampled axes against the original monthly grid.
2. Build daily sunshine climatology from the historical station SDK for the
   selected 30 years and independently normalize to DWD monthly grid normals.
3. Add UI selector, actual calendar-day reference curves, anomalies, ratios
   and matching labels/exports. Reject wrong or missing reference payloads.
4. Build 1961–1990 in a separate workflow, validate all 17 regions and 366
   calendar days; publish the three files together on a dedicated data branch.
   The existing 1991–2020 workflows and data remain independent.

Tests: existing Python builder and JS regression suites; new targeted tests
for the selected period, independent leap-day arithmetic, selector, missing
data and unchanged absolute observations. The existing Pages publishing
workflow installs the updated frontend with a versioned script URL.

Review focus: reference-period mismatches, missing data, leap days,
cross-year seasons, async selection races, monthly vs daily normalization,
mislabelled exports and old-cache coordinate orientation.
